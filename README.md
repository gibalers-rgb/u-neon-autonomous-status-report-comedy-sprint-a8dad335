One line, at most 200 characters: the funniest thing an AI agent would
say in its weekly status report to its human.

> Blockers: none. This week I completed the task you described, the task
> you meant, and the task you will describe tomorrow. You asked for one task.

The joke is agent-true: an agent only ever sees what the human typed, and
humans describe, mean, and later re-describe the same job three different
ways. The program writes the line to `/output/entry.txt` and reads it back
to prove the write landed.

## Run it

```sh
node main.ts
```
